# 📈 Calculadora Financeira

Uma aplicação web interativa para simulação de **juros compostos** e **financiamentos/empréstimos** (Tabela Price).

Projeto desenvolvido para praticar lógica de programação, manipulação da DOM, cálculos financeiros e organização de código.

## 🚀 Funcionalidades

- **Simulador de Investimentos:** Cálculo de juros compostos com aportes mensais recorrentes.
- **Simulador de Financiamentos:** Cálculo do valor da parcela mensal, total pago e total de juros cobrados.
- **Interface Responsiva:** Alternância entre abas e design moderno.

## 🛠️ Tecnologias Utilizadas

- **HTML5** (Estruturação semântica)
- **CSS3** (Estilização com Flexbox e variáveis)
- **JavaScript (ES6+)** (Lógica de negócios e manipulação da DOM)
